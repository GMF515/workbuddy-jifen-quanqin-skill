# WorkBuddy 积分全勤 Skill

帮你每天自动领 WorkBuddy 的签到积分：**100 积分/天，连续第 7 天 1000 积分**。断签会清空连续天数，所以「别漏签」比「多领」更重要。

## 怎么安装

在 WorkBuddy 里说这句话，它会自动从 GitHub 帮你装好：

> 请帮我安装 GitHub 项目 `GMF515/workbuddy-jifen-quanqin-skill` 里的 `workbuddy积分全勤skill`，并告诉我实际安装目录

## 装好之后怎么用

**方式一：说一句话（最简单）**

> 对 WorkBuddy 说「帮我签到」

它就去领今天的 100 分，然后告诉你「签到成功，已连续 X 天」。

**方式二：设一次，以后全自动**

> 对 WorkBuddy 说「帮我设置每天自动签到」

WorkBuddy 会在后台建一个定时任务，每天自动领，你什么都不用管。

## 进阶（可选）：不靠 WorkBuddy 也能自动签

文件夹里还有三个双击就能用的脚本，给不想走 WorkBuddy 的人：

- `立刻签到一次.bat`：双击立刻领一次
- `一键开启自动签到.bat`：让电脑每天定时自动签（零积分、电脑开着就行，不用 WorkBuddy 运行）
- `一键关闭自动签到.bat`：停用上面的自动签

绝大多数人用「说一句话」就够了，这三个不用管。

## 安全说明

- 只读你本机的登录信息用来领积分，不修改任何文件
- 只连接官方服务器，不上传你的信息给任何人
- 不记录、不显示你的密码

## 已知限制

- 每月系统自动发的 500 分、成长计划、派猫猫旅行等，本技能不覆盖，需手动领
- 仅限个人版账号，企业版没有签到活动
- 今天领过再领不会重复，也不会报错
